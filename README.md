# docassemble.TXAuthorizationForNonparentCareOfAChild

Use this form to give another adult temporary permission to care for your child. The agreement usually lasts six months and renews automatically. If Texas law requires court approval, get a written court order approving the agreement before signing or using it. Sign in front of a notary.
